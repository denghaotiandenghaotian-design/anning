## 一、社工在安宁疗护中的介入

第一章回答了"什么是安宁疗护"。我们沿着"全人、全家、全程、全队"的理念继续追问：在由多学科团队共同提供的服务中，社会工作者处于什么位置、发挥什么作用？这正是本章要回答的问题。概括而言，社工在安宁疗护中的核心作用，是**提供社会心理服务**——以心理社会评估为起点，以情绪支持、哀伤辅导、家庭工作、死亡教育协助、资源链接与团队协调为主要内容，贯穿患者照护全程，并延伸至丧亲之后的家庭。

> 这一角色定位有明确的标准与文献依据：卫生行业标准 **《老年安宁疗护病区设置标准》（WS/T 844—2024）** 将社会工作者列为安宁疗护团队固定成员，规定其"评估患者、患者家属及主要照顾者的社会、精神心理层面的需求；提供心理辅导和社会支持，链接社会资源，协助制定出院计划，维护老年患者生命尊严；支持安宁疗护团队成员；管理志愿者及志愿服务"。
>
> 国内研究亦指出，医务社会工作者作为安宁疗护多学科团队的重要成员，在实践中扮演评估者、支持者、协调者等多重角色，作用独特；美国国家医学院（IOM）2015 年报告《Dying in America》同样将社会工作者列为缓和照护跨学科团队的当然成员，视社会心理照护为缓和照护的核心组成。

## 二、专业定位与角色

| 角色 | 主要职责 |
| --- | --- |
| 评估者 | 对患者的生理—心理—社会—灵性状况及家庭系统开展综合评估，动态识别需求与风险（如自杀风险、哀伤风险、照护者耗竭）。 |
| 直接服务者 | 运用个案工作、小组工作、社区工作方法，提供情绪支持、哀伤辅导、家庭工作、死亡教育协助等直接服务。 |
| 协调者 | 作为多学科团队的沟通桥梁，参与团队查房与个案讨论，促进医疗、护理、心理、社工、志愿服务的无缝衔接。 |
| **MDT 团队成员** | 作为多学科团队（MDT）的固定成员参加团队查房与个案讨论，负责心理社会评估与信息整合，向团队报告患者及家属的心理社会状况与需求变化，协助组织家庭会议，推动医疗、护理、心理、社工、志愿服务基于共同照护计划无缝协作，并为团队成员提供心理支持。 |
| 资源链接者 | 链接医疗救助、慈善资源、政策福利、志愿服务等正式与非正式资源，构建患者的社会支持网络。 |
| 教育者 | 向患者家属及公众开展死亡教育与照护知识教育，提升家庭照护能力与社会死亡素养。 |
| 倡导者 | 维护患者自主权与尊严，在团队与制度层面倡导以患者及家属为中心的照护。 |

> **E-CARE 五维核心能力框架**（基于系统评价，BMC Palliative Care 2025）：
> - **E**thics 伦理
> - **C**oordination 协调
> - **A**ssessment 评估
> - **R**esource Allocation 资源分配
> - **E**ducation 教育
>
> 可作为社工专业能力建设与考核的参照。

### 团队运作实证

- 国内社区安宁疗护 **"多专业团队"（H-MPT）模式**的构建研究显示：以全科医生、护士为主体、以**医务社会工作者为纽带的团队结构**，有助于提升安宁疗护总体服务质量与团队协作效率，并增进团队与家属对医务社会工作的认可。
- Reese 与 Sontag 对临终关怀团队的研究亦表明：**跨专业协作的有效性直接影响社会工作者专业作用的发挥**。

## 三、服务原则与服务流程

### 服务原则

- **服务对象自决**
- **全人服务**
- **全家照顾**
- **全程服务**
- **多学科协作**

### 服务流程

按照社会工作通用过程模式，依次为：

```
接案 → 预估 → 计划 → 介入 → 评估 → 结案
```

需具备特定条件时，可采用第四章第五部分所列专业介入方法（如尊严疗法、意义疗法、叙事疗法等）。

## 四、社工核心工作清单

- ✅ 参与多学科团队查房与个案讨论
- ✅ 完成心理社会评估（SAS/SDS/SSRS/AGS/PDI 等）
- ✅ 识别高危风险（自杀风险、照护者耗竭、复杂性哀伤风险）
- ✅ 提供情绪支持与死亡教育协助
- ✅ 召开家庭会议、促进沟通
- ✅ 链接医疗救助、慈善、政策福利
- ✅ 培训志愿者与公众宣教
- ✅ 倡导以患者为中心的照护模式

## 五、社工伦理边界（详见第九章）

1. **保密与保密例外**：保护患者隐私，但存在自伤/伤人风险时必须打破保密
2. **文化敏感性**：尊重不同民族、宗教的生死观
3. **不替代家庭决策**：保持中立协调者角色
4. **专业边界**：中重度精神心理症状及时转介，不越位处理
5. **记录规范**：会谈记录、过程评估、结案归档完整

> 关于伦理规范的完整内容（依据、原则、实务议题、守则要点、速查卡），统一收口到 **第九章伦理规范** 集中查阅。
