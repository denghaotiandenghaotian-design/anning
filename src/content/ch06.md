## 一、个案工作流程

```
接案（识别与转介、知情同意、危机程度初判）
   ↓
预估（生理—心理—社会—家庭—经济多维度问题与需求评估，完成基线测量）
   ↓
计划（商定总目标与具体目标，选定理论模式与干预方法，签订服务契约）
   ↓
介入（分阶段实施，动态评估与调整）
   ↓
评估（前后测对比与质性反馈）
   ↓
结案（目标达成确认、支持网络交接、回访计划）
```

## 二、需求评估：维度、工具与判定

评估遵循**"量表测量 + 访谈观察 + 关键他人核实"**相结合的原则。先以标准化工具判定"有没有问题、严重程度如何"，再以访谈澄清问题的性质与需求，据此选择理论框架并制定干预方案。

### 评估工具速查表

| 评估维度 | 工具 | 结果判定（参考） | 指向的需求 |
| --- | --- | --- | --- |
| 焦虑 | 焦虑自评量表 SAS（Zung）；广泛性焦虑量表 GAD-7 | SAS 标准分 ≥50：50—59 轻度、60—69 中度、≥70 重度；GAD-7：0—4 无、5—9 轻度、10—14 中度、15—21 重度 | 情绪安抚、放松训练、认知干预 |
| 抑郁 | 抑郁自评量表 SDS（Zung）；患者健康问卷 PHQ-9 | SDS 标准分 ≥53：53—62 轻度、63—72 中度、≥73 重度；PHQ-9 ≥10 提示中度及以上抑郁 | 心理支持、行为激活、转介心理/精神科 |
| 自杀风险 | 直接访谈（意念、计划、手段、意图）+ 风险评估表 | 存在明确计划、可及手段或强烈意图者列为高危，立即启动危机介入 | 安全优先、危机干预 |
| 预期性哀伤 | 预期性悲伤量表 AGS；晚期癌症患者预期性悲伤量表 PGAC | 依所用版本常模判定轻、中、重度 | 哀伤辅导、生命回顾、家庭会谈 |
| 复杂性/延长哀伤 | 复杂性哀伤量表 ICG（Prigerson）；ICD-11 延长哀伤障碍标准 | ICG ≥25 提示高风险；ICD-11 要求丧亲后症状持续逾 6 个月且造成功能损害 | 转介专业哀伤治疗，社工支持性跟进 |
| 社会支持 | 社会支持评定量表 SSRS（肖水源） | 主观支持、客观支持、支持利用度三个维度，总分越低支持越不足 | 资源链接、支持网络构建、照顾者支持 |
| 功能与生存期 | 卡氏功能状态量表 KPS；姑息功能量表 PPS | 多地以 KPS ≤70 或 PPS 提示预期生存期 ≤6 个月作为服务匹配参考 | 服务层级与强度匹配 |
| 症状负担 | 埃德蒙顿症状评估量表 ESAS；疼痛 NRS | 各症状 0—10 分自评，动态追踪 | 转介医护处理、症状管理配合 |
| 尊严感 | 患者尊严量表 PDI | 分数越高尊严困扰越重 | 尊严疗法、意义建构 |
| 老年抑郁 | 老年抑郁量表 GDS（30 项版） | 总分 ≥11 分提示抑郁可能，≥21 分提示中重度，适合老年人群筛查 | 抑郁情绪干预、陪伴与哀伤疏导 |
| 日常生活能力 | Barthel 指数（ADL） | 评分越低提示生活依赖程度越高，需匹配相应照护与协助安排 | 照护资源协调、生活支持 |
| 生命意义感 | 生命意义感量表（如 PIL） | 低分提示无意义感与自我价值感低下 | 生命回顾、意义建构干预 |
| 哀伤的质性识别 | 哀伤三要素观察（失落、孤独、未完成事件） | 三要素明显者即提示哀伤辅导需求，即使量表得分未达临界值 | 哀伤辅导、未竟事宜处理 |
| 孤独感 | 孤独感量表（如 UCLA 孤独量表简版） | 高分提示孤独与社会隔离 | 陪伴服务、社会交往重建 |

> **SAS/SDS 标准分 = 粗分 × 1.25**；上述界值为国内通行用法，具体以各工具手册及所用版本的常模为准。
>
> **ICG ≥25** 为国际哀伤研究常用界值；**ICD-11** 将延长哀伤障碍列为独立诊断单元（丧亲后持续逾 6 个月且功能受损）。

## 三、理论依据及其回应的需求

| 理论 | 提出者/来源 | 核心观点 | 回应的需求 |
| --- | --- | --- | --- |
| ADAPTS 哀伤评估与干预配对模式 | 周燕雯（香港大学） | 哀伤反应呈现六个面向：异常情绪、功能失调认知、适应困难、生理症状、创伤反应、分离痛苦。干预前先评估并定位个体主导的痛苦面向，再配对针对性方法。 | 哀伤者差异化大、需求各异的精准评估与干预需求 |
| 持续联结理论 | Klass、Silverman、Nickman（1996） | 哀伤的目标不是切断与逝者的关系，而是将其转化为以记忆、仪式、传承为载体的持续性心理联结。 | 与逝者保持联结、完成未竟关系的心理需求 |
| 依恋理论 | Bowlby | 丧亲激活个体的依恋系统，分离痛苦强度与依恋类型相关：安全依恋者哀伤适应相对平稳，焦虑/矛盾依恋者更易出现强烈而持久的分离痛苦。 | 分离痛苦、个体化哀伤风险的识别与安抚 |
| 生命周期理论 | Erikson | 老年期的发展任务是"自我整合对绝望"：能够回顾一生并接纳其圆满与遗憾者获得智慧感，得以安然面对终点。 | 生命意义感、自我整合与"善终"的心理需求 |
| 叙事治疗与生命回顾 | White & Epston；Butler（1963） | 人借助"故事"理解自身生命；引导服务对象讲述、整理并重构生命故事，可重建自我认同与生命意义。 | 生命意义感缺失、自我认同困扰 |
| 尊严疗法 | Chochinov（加拿大） | 通过结构化人生回顾与寄语整理，协助临终者确认自身价值、留下传承，维护临终尊严。 | 尊严维护、人生价值传承 |
| 意义建构理论 | Neimeyer | 丧亲的本质是原有意义世界的破碎，适应的关键在于重建意义、重新安放与逝者的关系。 | 复杂性哀伤、意义重建 |
| 社会支持理论 | Caplan、Cassel 等 | 支持网络兼具工具性与情感性功能，可缓冲压力；正式支持与非正式支持需协同动用。 | 支持网络薄弱、孤独 |
| 优势视角 | Saleebey | 聚焦服务对象的能力、资源与成功经验，以优势为改变的基础。 | 无用感、自我否定 |
| 任务中心模式 | Reid & Epstein | 短程介入，与服务对象共同确定具体、可操作的任务并分步完成。 | 目标具体、需限期达成的个案 |

## 四、常见问题类型、干预参考线与干预方法

| 问题类型 | 评估工具与干预参考线 | 主要干预方法 |
| --- | --- | --- |
| 死亡焦虑/焦虑情绪 | SAS ≥60（中度）或 GAD-7 ≥10；或主观痛苦明显、影响睡眠与进食 | 放松训练、正念呼吸、认知重构、生命教育；配合园艺、音乐等转移性活动；重度者转介心理治疗。 |
| 抑郁情绪 | SDS ≥63（中度）或 PHQ-9 ≥10 | 心理支持、行为激活、生命回顾；中重度转介心理或精神科评估。 |
| 自杀风险 | 有明确意念、计划或手段；量表筛查阳性 | **危机介入模式**：制定安全计划、消除环境中危险因素、加强巡视与监护、多方联动、必要时医疗转介；**生命安全优先**于一切服务议程。 |
| 预期性哀伤/丧亲哀伤 | AGS/PGAC 提示中重度；丧亲早期情绪崩溃、社会功能受损 | 哀伤辅导（正常化哀伤、鼓励表达）、生命回顾、持续联结取向的纪念活动（整理遗物、制作纪念册）、家庭会谈。 |
| 复杂性/延长哀伤 | ICG ≥25，或符合 ICD-11 延长哀伤障碍标准 | 转介专业哀伤治疗（如延长哀伤治疗），社工提供支持性跟进与资源链接。 |
| 社会支持不足 | SSRS 各维度得分偏低、支持网络单一 | 链接正式支持（医护、社工、政策、慈善），激活非正式支持（家属、朋辈、志愿者），组织或转介支持小组。 |
| 家庭沟通障碍/未竟事务 | 家庭访谈、家庭结构图评估发现沟通回避或冲突 | 家庭会议、分别会谈+共同会谈、生前预嘱沟通协助；社工保持中立协调者角色，不替代家庭决策。 |
| 经济与政策需求 | 经济收入、医保与救助政策核查 | 医疗救助与慈善资源链接、政策解答、事务性协助。 |
| 生命意义感缺失/自我价值感低 | 生命意义感量表低分；持续出现"无用""拖累家人"等自我否定表述 | 生命回顾、生命意义树（根—枝—叶—花—果）、人生故事手账本、尊严疗法、生命故事分享会等叙事性干预。 |
| 老年抑郁情绪 | GDS ≥11 分提示抑郁可能，≥21 分提示中重度 | 陪伴访谈、文娱活动破冰、哀伤疏导；中重度或持续高分者转介精神心理科。 |
| 躯体症状痛苦/舒适照护需求 | NRS ≥4 分且影响睡眠或持续加重；ADL 下降提示依赖加重 | 联动多学科调整镇痛与护理方案；以怀旧音乐、棋牌、手工等转移注意力；建立护工—医护—家属—社工四方联动机制。 |
| 孤独与社会隔离 | 孤独感量表高分；社会生态系统图显示社交断裂、回避集体活动 | 以兴趣活动（棋牌、老歌等原有爱好）破冰建立关系；链接院内同伴与集体活动；搭建家庭线上陪伴约定（如每周视频、每月探视）。 |
| 数字生活适应困难 | 观察评估：不能直接使用通讯、娱乐类智能设备 | 适老化数字教学（微信语音视频、音乐软件等），小步子反复实操并布置家庭练习；尊重案主自主取舍，身体条件不允许的项目不作硬性目标。 |
| 防御性强、抗拒倾诉的丧亲者 | 访谈中回避丧亲话题、拒绝深入，初期防御明显 | 以兴趣活动先行破冰建立信任；分层渐进引入哀伤议题，设置随时暂停的安全约定；以口述告别信、书信录音等完成未竟事宜，避免直接触碰创伤。 |

## 五、分阶段实施要点

### 第一阶段：关系建立与基线测量

- 以陪伴者姿态开展初次会谈
- 完成知情同意
- 澄清核心困扰
- 完成焦虑、抑郁、哀伤、社会支持等基线测量
- 探索家庭系统
- 与服务对象商定目标，签订服务契约

### 第二阶段：计划制订

- 依据所选理论将抽象需求转化为**具体、可衡量、有时限**的目标
- 明确双方角色与任务
- 发掘服务对象兴趣与优势，使计划贴合其意愿

### 第三阶段：计划实施

按方案开展会谈与活动，常见内容依次为：

1. 危机干预与安全计划（如有自杀风险，置于首位）
2. 情绪稳定化训练
3. 生命回顾
4. 哀伤辅导
5. 家庭会谈
6. 资源链接

> **动态评估**：当服务对象当下状态不适宜推进既定议程时，优先情绪安抚，灵活调整节奏。

### 第四阶段：成效评估与结案

- 以后测对比基线，量化症状缓解程度
- 收集服务对象满意度及关键他人（家属、护工、医护）的质性反馈
- 确认目标达成后结案，完成支持网络交接并约定回访安排

## 六、效果评估方法

1. **基线测量法**：介入前、中、后定期复测量表，对比变化幅度
2. **服务对象影响评估**：满意度测量、差别影响分析、关键他人访谈
3. **任务达成与目标实现程度测量**：对具体任务和目标逐项核对完成度
4. **过程评估**：检视会谈是否按结构开展、干预技巧运用是否得当、记录是否完整规范

## 七、实务总结

1. **生命优先**：自杀风险动态监测贯穿全程，危机干预优先于一切服务议程
2. **身心社灵整合**：慢性终末期患者的心理痛苦常与躯体症状互为条件（症状—恐惧的条件反射），需与医护团队联动，身心同步干预
3. **理论服务于需求**：先评估、再选理论、后干预
4. **动态评估与弹性调整**：每次接触均重新评估状态与风险
5. **伦理守则**：知情同意、保密及保密例外、尊重自决与文化信仰
6. **团队联动与转介边界**：明确社工与医护、心理治疗的职责边界
