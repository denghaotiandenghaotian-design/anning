## 一、服务场所

### 1. 独立设置的安宁疗护中心（病区）

须符合国卫医发〔2017〕7 号文件规定的基本标准和管理规范，设有**关怀室（告别室）**。

### 2. 医疗机构内的安宁疗护床位

综合医院、中医医院、专科医院可在**肿瘤科、老年科、疼痛科**等相关科室设立安宁疗护床位或工作小组。

### 3. 医养结合与福利机构

养老机构、社会福利院、护理院等可为机构内的疾病终末期老年人提供安宁疗护服务。

### 4. 社区与居家

社区卫生服务中心、乡镇卫生院可结合**家庭病床、上门服务**等开展居家安宁疗护。

> 四种场所可相互转介，服务随患者所在场景延伸。

## 二、服务形式

- **门诊服务**：症状评估、随访、心理支持
- **住院服务**：终末期急性症状控制
- **机构内服务**：养老/护理院驻点
- **居家服务**：上门访视、家庭病床

> 患者可在不同场所之间转介，服务随患者所在场景延伸。

## 三、服务团队

| 角色 | 主要职责 |
| --- | --- |
| 执业医师 | 症状评估、用药决策、整体治疗方向 |
| 执业护士 | 基础护理、症状监测、给药与舒适照护 |
| 医务社会工作者 | 心理社会评估、情绪与家庭工作、资源链接、团队协调 |
| 心理咨询师 | 心理评估与治疗、危机干预 |
| 药师 | 镇痛与对症药物咨询、不良反应监测 |
| 营养师 | 营养评估与方案 |
| 康复治疗师 | 功能维持、舒适体位 |
| 志愿者 | 陪伴、生活协助、纪念活动支持 |

> **医务社工是团队中负责心理社会评估、情绪与家庭工作、资源链接及团队协调的专业成员**，是安宁疗护多学科团队的关键角色。

## 四、服务内容边界

安宁疗护的服务内容为：

1. **症状控制**（疼痛及其他症状）
2. **舒适照护**（口腔、皮肤、体位、排泄等基础护理）
3. **心理精神及社会支持**（倾听、哀伤辅导、家庭工作）
4. **人文关怀与善终服务**（死亡教育、尊严维护、生命回顾）

> 进入安宁疗护须签署知情同意；除对症、支持性措施外，不再实施以治愈为目的的创伤性治疗。
>
> 各地对"不实施心肺复苏、插管等抢救"的具体规定**以当地规范为准**。
